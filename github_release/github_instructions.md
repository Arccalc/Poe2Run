# Инструкция по публикации проекта на GitHub

В этой папке подготовлены все файлы, необходимые для создания репозитория и публикации первого релиза приложения.

---

## Шаг 1. Инициализация Git и отправка кода на GitHub

Если у вас еще не инициализирован Git в папке проекта:

1. Откройте терминал (PowerShell или Git Bash) в папке проекта (`c:\Users\Ilyuha\Desktop\speedruntool`).
2. Выполните инициализацию репозитория:
   ```bash
   git init
   ```
3. Добавьте все файлы в индекс (служебные файлы сборки автоматически игнорируются благодаря `.gitignore`):
   ```bash
   git add .
   ```
4. Сделайте первый коммит:
   ```bash
   git commit -m "Initial commit: PoE2 Speedrun Timer v0.1.0"
   ```
5. Перейдите на [GitHub](https://github.com/) и создайте новый **публичный** или **приватный** репозиторий (например, с именем `poe2-speedrun-timer`). **Не ставьте галочки** на создание README, LICENSE или .gitignore, так как они уже созданы локально.
6. Скопируйте ссылку на созданный репозиторий и привяжите его локально (замените `ВАШ_ПСЕВДОНИМ` и `ИМЯ_РЕПО` на ваши данные):
   ```bash
   git remote add origin https://github.com/ВАШ_ПСЕВДОНИМ/ИМЯ_РЕПО.git
   ```
7. Переименуйте ветку в `main` и отправьте код на GitHub:
   ```bash
   git branch -M main
   git push -u origin main
   ```

---

## Шаг 2. Создание релиза (Publish Release) на GitHub

Чтобы пользователи могли скачивать готовый установщик, создайте релиз на GitHub:

1. Перейдите на страницу вашего репозитория на GitHub.
2. В правой колонке найдите раздел **Releases** и нажмите **Create a new release** (или *Draft a new release*).
3. В поле **Tag version** введите версию, например: `v0.1.0`.
4. В поле **Release title** введите название релиза, например: `Release v0.1.0 - Early Access`.
5. В поле описания (Write) вы можете кратко описать релиз или вставить текст:
   ```markdown
   ## Что нового в версии 0.1.0:
   - Полная автоматическая отсечка времени (Splits) по логам PoE 2.
   - Поддержка перетаскивания сегментов (Drag & Drop) внутри Актов.
   - Динамическая группировка интерлюдий при прохождении в произвольном порядке.
   - Кнопка "Resume Run" для возобновления забегов с загруженного файла.
   - Прозрачный оверлей с поддержкой "Just Timer" (только таймер).
   ```
6. **Самый важный шаг**: Прокрутите страницу вниз до зоны **Attach binaries by dropping them here or selecting them**.
7. Перетащите в эту зону файлы установщиков из папки `github_release`:
   - `PoE2SpeedrunTimer_0.1.0_x64_en-US.msi` (Рекомендуемый установщик)
   - `PoE2SpeedrunTimer_0.1.0_x64-setup.exe` (Альтернативный EXE-установщик)
8. Нажмите кнопку **Publish release** (Опубликовать релиз).

Готово! Теперь любой пользователь сможет зайти в ваш репозиторий, перейти во вкладку *Releases* и скачать готовый установщик приложения.
